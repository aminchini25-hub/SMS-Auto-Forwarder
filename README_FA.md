# SMS Auto Forwarder — نسخه کامل

این پروژه نسخه ادغام‌شده و اصلاح‌شده است و برای **Samsung، Xiaomi، Redmi و POCO** طراحی شده است.

## کار برنامه

کاربر فقط یک بار:

1. فرستنده A را وارد می‌کند (شماره تلفن یا Sender ID متنی مثل `BANK`).
2. شماره گیرنده B را وارد می‌کند.
3. گزینه فوروارد خودکار را فعال می‌کند.
4. مجوزهای `RECEIVE_SMS` و `SEND_SMS` را از خود اندروید تأیید می‌کند.

بعد از آن، فقط SMSهای جدیدی که فرستنده‌شان با A تطبیق داشته باشد، به B ارسال می‌شوند.

## امکانات این نسخه

- Kotlin
- رابط موبایل‌پسند با Dark/Light Mode
- پشتیبانی RTL و ترجمه فارسی
- بدون اینترنت، Analytics یا Server
- بدون مجوز `READ_SMS`
- پشتیبانی Sender ID متنی
- تبدیل اعداد فارسی/عربی به انگلیسی
- تطبیق رایج `0912...` و `+98912...`
- جلوگیری از تطبیق اشتباه Senderهای متنی با «۱۰ کاراکتر آخر»
- پشتیبانی SMS چندبخشی/طولانی
- ثبت وضعیت واقعی ارسال/خطا با PendingIntent
- گزارش Delivery در صورت پشتیبانی اپراتور
- راهنمای Samsung و Xiaomi داخل برنامه
- سازگار با Android 6.0+ (`minSdk 23`)
- `compileSdk 36` و `targetSdk 36`
- GitHub Actions برای ساخت APK بدون Android Studio
- تست واحد برای منطق تطبیق فرستنده

## ساخت با Android Studio

این پروژه از **Android Gradle Plugin 9.3.1** استفاده می‌کند و Gradle 9.5.0 / JDK 17 مناسب آن است.

پروژه را در Android Studio باز کنید، Sync را انجام دهید و سپس:

`Build → Build Bundle(s) / APK(s) → Build APK(s)`

## ساخت APK فقط با GitHub

فایل زیر از قبل داخل پروژه قرار گرفته:

`.github/workflows/build-apk.yml`

پروژه را داخل یک Repository در GitHub قرار دهید و از بخش Actions، Workflow با نام **Build Android APK** را اجرا کنید.

خروجی قابل نصب به‌عنوان Artifact با نام:

`SMS-Auto-Forwarder-APK`

در دسترس خواهد بود.

## نکته گوشی دو سیم‌کارته

این نسخه عمداً مجوز اضافه برای خواندن اطلاعات SIM نمی‌گیرد. ارسال از **SIM پیش‌فرض SMS اندروید** انجام می‌شود. اگر گوشی دو سیم‌کارته است، SIM پیش‌فرض پیامک را از تنظیمات گوشی تعیین کنید.

## سامسونگ

برای پایداری بیشتر:

`Settings → Apps → SMS Auto Forwarder → Battery → Unrestricted`

## شیائومی / Redmi / POCO

- `Background autostart` را روشن کنید.
- `Battery / Battery saver → No restrictions`

## حریم خصوصی

برنامه فقط در صورت فعال بودن فوروارد تلگرام یا Webhook از `INTERNET` استفاده می‌کند، هیچ اطلاعاتی جز محتوای همان پیام را جای دیگری آپلود نمی‌کند و پیام‌های قدیمی را نمی‌خواند.

> برای OTP، کد بانکی یا پیام‌های محرمانه فقط وقتی از این قابلیت استفاده کنید که گیرنده صراحتاً مجاز و مورد اعتماد باشد.

# Build notes

This archive does not include a fabricated Gradle wrapper JAR.

Use one of these supported paths:

1. Android Studio with Gradle 9.5.0 / JDK 17, or
2. The included GitHub Actions workflow, which installs Gradle 9.5.0 explicitly and builds `app-debug.apk`.

Android Gradle Plugin is pinned to 9.3.1 and compile/target SDK are pinned to 36.
